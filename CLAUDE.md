# CLAUDE.md

## Project Overview
DataMan is a Flask-based educational math game application designed to make practicing math interactive and engaging.

The application includes:
- User authentication
- Multiple math game modes
- Performance tracking
- Dashboard analytics
- Database integration

---

# Development Workflow

This project followed the Sacred Workflow process:

1. Create GitHub Issue
2. Create feature branch
3. Open Pull Request
4. Implement feature
5. Commit changes
6. Push branch
7. Merge Pull Request

---

# Branch Strategy

Features were developed using separate branches such as:

- feature/1-login-page
- feature/number-guesser
- feature/speed-round
- feature/fill-it-in
- feature/dashboard-stats
- feature/ui-polish
- feature/readme
